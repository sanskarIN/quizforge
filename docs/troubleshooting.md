# Troubleshooting

## `flutter` is not recognized

Install Flutter stable, add Flutter's `bin` directory to `PATH`, restart the terminal, and run:

```bash
flutter doctor -v
```

## Platform directory is missing

QuizForge keeps runner generation reproducible. From the repository root:

```bash
flutter create . --platforms=android,ios,web,windows,macos,linux
```

Generate only platforms supported by your host/toolchain if necessary.

## `flutter pub get` fails

- Check internet connectivity to the Dart/Flutter package registry.
- Confirm the installed Dart SDK satisfies the `pubspec.yaml` constraint.
- Avoid manually editing package cache files.
- Run `flutter pub outdated` to inspect dependency resolution.

## Analyzer errors after a Flutter upgrade

Run:

```bash
flutter --version
flutter pub get
dart format lib test
flutter analyze
```

If a framework API changed, fix source against the current stable API and add/update tests rather than disabling analyzer rules globally.

## Tests fail because a plugin is unavailable

Domain tests should remain plugin-independent. Persistence tests use in-memory SQLite. If a widget/integration test reaches a platform plugin, initialize or mock only the boundary required by that test rather than weakening production code.

## App starts with an initialization error

Initialization opens the local database, loads settings, seeds questions when needed, and prepares a local profile. Capture the user-safe error text and run the application from a terminal for additional Flutter diagnostics. Do not post private data or secrets with logs.

If a database created by a future schema version is involved, preserve a copy only if it contains no sensitive data and investigate migration compatibility before deleting it.

## Question import reports errors

QuizForge imports only its supported schema.

For JSON, confirm the root object contains a `questions` array and each question has the required fields/types.

For CSV, use an export generated by QuizForge as the canonical header/escaping example. Choice, answer, and tag list fields are JSON arrays stored inside CSV cells.

Invalid rows are reported and not persisted. Duplicate ids or duplicate normalized fingerprints are skipped.

## Import says a question is a duplicate

Questions are considered duplicates when either:

- the id already exists; or
- normalized category + question type + normalized prompt matches existing content.

Whitespace/casing changes alone do not create a distinct question.

## Timed quiz advances automatically

That is expected when the timer reaches zero. The unanswered question is submitted as incorrect and the quiz continues.

## Local progress appears empty

Progress is profile-specific. Check the active profile in Settings. Each local profile has independent progress and bookmarks.

## Links in About do not open

External links use the operating system/browser URL handling. Ensure the platform has an available browser or mail handler. On restricted environments, copy the displayed address manually.

## Web persistence problems

Before treating a web persistence issue as general app data loss:

- build the web target in release mode;
- verify required Drift web runtime assets for the exact dependency version;
- test in a normal browser profile rather than only a restrictive/private mode;
- inspect browser storage/quota errors;
- confirm reload persistence separately from hot-reload behavior.

## Windows/macOS/Linux build errors

Desktop Flutter builds depend on host-native compiler/tooling. Run `flutter doctor -v` and install the platform prerequisites. A source-level fix should not replace missing host tooling.

## Android signing errors

The public repository does not contain private release signing material. Create signing configuration outside source control and follow platform/store guidance. Never commit a keystore or signing password.
